# What the program does
This program runs an updated version of the famous "Pong" game where the user randomly flips sides with the computer. Users can run the game in their desktop or on the web. users have the option to play the computer at different difficulty levels either in standard pong or flip pong.

# Commands to Run

1. "pip install -r requirements.txt" (RUN ONCE)
2. "python -m pytest" ---> runs tests
3. "python game/main.py" ---> runs the game in your desktop
4. "python -m pygbag game" ---> runs the game in your browser
