# What it does

This program is a near-identical version of the original pong game with one twist: both sides flip randomly.

# System

    1. Main menu
        - title: large block letters spelling "Pong" centered
        - "start" button under title --> red button -->, white text, saturation increase when mouse hovers over
        - "controls" button under "start" button --> red button, white text, saturation increase when mouse hovers over
        - "exit" button under "controls" button --> red button, white text, saturation increase when mouse hovers over

    2. When Start is clicked:
        - left side of screen: computer difficulty slider (three levels)
        - right side of screen: side switcher randomness slider (enabled vs disabled)
        - bottom left of screen: go back button --> red button, white text, saturation increase when mouse hovers over
        - bottom right of screen: start game button --> red button, white text, saturation increase when mouse hovers over

    3. When Controls is clicked:
        - up/down: up/down arrows or w/s keys (when side switched, left/right arrows or a/d keys)
        - bottom left of screen: go back button --> red button, white text, saturation increase when mouse hovers over

    4. When Exit is clicked:
        - game closes
